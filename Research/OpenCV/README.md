# OpenCV Object Tracking Prototype

This folder contains a command-line prototype for tracking one object in a user-supplied MP4 clip. It asks you to select the object in the first frame, saves that selected region as an image, follows it with OpenCV's CSRT tracker, and writes a CSV trajectory plus an annotated preview video. Example images or model training are not needed for this manual selection workflow.

## Create the Conda environment

From the repository root, create and activate the dedicated environment:

```powershell
conda env create -f environment.yml
conda activate video-tracking
```

The environment uses Python 3.11 and the conda-forge OpenCV package. The package supplies the `cv2` Python module and OpenCV's native libraries. Do not also install `opencv-python`, `opencv-contrib-python`, or their headless variants with pip in this environment; they install overlapping `cv2` files.

## Run

From the repository root, run:

```powershell
python .\Research\OpenCV\track_object.py "C:\path\to\your\clip.mp4"
```

In the ROI window, drag a box around the target and press **Enter** or **Space** to accept it. Press **C** to cancel. The selection window requires a desktop session and a GUI-enabled OpenCV build.

To reuse a previously saved one-row ROI CSV and skip interactive selection, pass its path with `--roi-csv`:

```powershell
python .\Research\OpenCV\track_object.py "C:\path\to\your\clip.mp4" --roi-csv "C:\path\to\tracked_output\your_clip_roi.csv"
```

The ROI CSV must contain one data row with `x`, `y`, `width`, and `height` columns in whole-pixel coordinates. Files generated by this script also include `center_x` and `center_y`; those columns are not needed to load the ROI because the center is derived from the box dimensions. The ROI must fit inside the first video frame.

The script creates `tracked_output` beside the source video and writes:

- `<video-stem>_roi.png`: unannotated crop of the selected region in the first frame.
- `<video-stem>_roi.csv`: one row with the initial region's `x`, `y`, `width`, `height`, `center_x`, and `center_y` in pixels. The origin is the frame's top-left; `x` increases right and `y` increases down. `x` and `y` mark the region's top-left corner.
- `<video-stem>_tracked.csv`: frame index, timestamp, tracking status, box coordinates, and center coordinates. Failed frames have blank coordinate fields.
- `<video-stem>_tracked.mp4`: annotated preview with a green target box on tracked frames and a lost-target label on failed frames.

The source video is not modified. Existing output files with the same names are replaced.

## Verify OpenCV features

```powershell
python -c "import cv2; print('OpenCV:', cv2.__version__); print('ROI selector:', hasattr(cv2, 'selectROI')); print('CSRT:', hasattr(cv2, 'TrackerCSRT_create') or hasattr(cv2, 'TrackerCSRT') or (hasattr(cv2, 'legacy') and (hasattr(cv2.legacy, 'TrackerCSRT_create') or hasattr(cv2.legacy, 'TrackerCSRT'))))"
```

CSRT's Python API location varies between OpenCV versions. If the script reports that CSRT is unavailable, confirm the conda-forge environment is active and was created from the repository-root `environment.yml`.

## Limitations

The tracker can drift or lose the object during occlusion, rapid motion, major appearance changes, or when similar objects overlap. Review the annotated preview and CSV. This prototype tracks one manually selected object; automatic person/ball detection and multiple-object tracking are not included.
